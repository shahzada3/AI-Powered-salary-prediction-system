# AI Salary Intelligence System

An end-to-end Machine Learning project that predicts employee salaries using Ensemble Learning algorithms.

## Features

- Salary Prediction
- Ensemble Learning
- Explainable AI (SHAP)
- Streamlit Dashboard
- Model Comparison

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- SHAP
- Streamlit
